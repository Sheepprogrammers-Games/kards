# 美术方向：回响 · ECHOES

适用范围：`assets/art/` 下全部素材，以及 `tools/artgen/` 生成管线的验收标准。
本文件是验收依据，不是参考建议。任何与本文件冲突的素材一律重做。

## 1. 视觉支柱

三条支柱各自可独立否决一件素材。审片时逐条过，任一条不过即打回。

**支柱一 · 剪影先于细节**
素材在 64 px 缩略、并填充为纯黑剪影后，仍能被辨认出所属类别与威胁等级；做不到就是废稿，细节再多也不补救。

**支柱二 · 全圣殿只有一个光源**
所有素材共用左上 45° 的古金主光与右下的深靛蓝补光；素材自带的任何发光体必须能指出它照亮了画面里的哪个表面，指不出就是装饰性光污染。

**支柱三 · 品红只表示回响**
品红是一条游戏规则的视觉编码，不是氛围色、不是紫色的替代品、不是通用魔法光；画面里出现品红时必须能说明它对应哪一次重演。

## 2. 三幕视觉演进

三幕共用同一套五色，不引入新色相。演进靠三色的**主导权转移**与**光源位置下沉**完成，不靠换色板。

### 第一幕 · 崩坏钟楼

| 项目 | 规定 |
|------|------|
| 场景主题 | 巨型钟楼内部，楼层塌陷，建筑尺度的齿轮卡在半途，彩窗碎片向上飘 |
| 光照逻辑 | 高位侧光。光从画面左上的破洞射入，形成清晰的体积光柱，投影方向一致向右下 |
| 色彩偏移 | 古金主导亮部，暖琥珀承担体积光，深靛蓝只在阴影。整体偏暖、中高对比 |
| 意图 | 教学幕，可读性优先。物体边界必须清楚，不允许大面积雾化 |

### 第二幕 · 逆位回廊

| 项目 | 规定 |
|------|------|
| 场景主题 | 失重的天体仪长廊，黄铜星环逆向缓转，碎石与积水向上流，回廊没有地板 |
| 光照逻辑 | 低位反光。主光从画面下方的地脉裂隙向上打，人物与敌人受底光，投影上翻。这是全篇唯一允许违反支柱二默认方向的幕，代价是主光必须可见地存在于画面内 |
| 色彩偏移 | 午夜蓝上升为主导，古金被压暗、氧化、只剩边缘高光，暖琥珀退为点状。整体偏冷、低对比 |
| 意图 | 压抑幕。可读性靠明度差而非色相差，因此剪影负担最重 |

### 第三幕 · 归零圣所

| 项目 | 规定 |
|------|------|
| 场景主题 | 圣殿核心，所有指针停在同一刻，历史上每一次回响同时显形并重叠 |
| 光照逻辑 | 无外部主光。唯一光源是回响本身，即品红自发光，由内向外照亮周围表面 |
| 色彩偏移 | 深靛蓝褪至近黑，古金转为白热高光，品红从点缀升为环境光。最高对比 |
| 意图 | 品红解禁的唯一一幕，但解禁的是环境光，不是主体涂装 |

## 3. 卡牌插画构图规范

生成后端会改变输出尺寸（实测请求 1024×1536 返回 848×1264），因此所有版式规定按**比例**给出，禁止用像素值。

| 项目 | 规定 |
|------|------|
| 主体占比 | 主体外接框占画面高度 55%–70%。低于 55% 主体太小，高于 70% 会被卡框裁到 |
| 顶部留白 | 上方 12% 为暗部空区，只允许有雾、光晕、无轮廓的背景 |
| 底部留白 | 下方 22% 为暗部空区，UI 在此压卡名与描述文字，不允许出现高对比细节 |
| 左右留白 | 左右各 8% 为安全边，主体与主体的发光外扩均不得进入 |
| 视线方向 | 主体的视线、面朝、或运动指向必须朝画面内侧且略向上；禁止看向观者正前方，禁止看向画面外的下角 |
| 光源方向 | 主光左上 45°、古金色；补光右下、深靛蓝色。禁止正面平光，禁止双侧对称打光 |
| 景深 | 前景与主体锐利，背景必须虚化或雾化，背景不得出现与主体同等锐度的结构 |

## 4. 三类牌的视觉区分

颜色不作为区分手段。三类牌都用同一套五色，靠**形状语言**、**构图轴**、**运动矢量**三项区分，任意一项做反即为不合格。

### 织（铺设回响）

| 项目 | 规定 |
|------|------|
| 形状语言 | 连续曲线、螺旋、编织线束、同心圆环。无锐角，无断口 |
| 构图轴 | 垂直中轴，接近对称 |
| 运动矢量 | 自下而上生长，向中轴收拢 |
| 主体位置 | 居中，底部有明确的根基或起点 |

### 引（放大已有回响）

| 项目 | 规定 |
|------|------|
| 形状语言 | 放射状、透镜、光锥、扇形展开、同心波前。以单点为圆心 |
| 构图轴 | 单点透视，焦点位于主体内部 |
| 运动矢量 | 沿深度轴由内向外，朝观者方向扩张 |
| 主体位置 | 居中偏上，焦点必须落在画面上 2/3 内 |

### 扰（破坏与位移）

| 项目 | 规定 |
|------|------|
| 形状语言 | 锐角、断裂面、错位的平行四边形、碎片、缺齿 |
| 构图轴 | 强对角线，左下至右上 |
| 运动矢量 | 横向剪切，主体两侧存在明显错位 |
| 主体位置 | 偏离中轴至少画面宽度的 8%，禁止对称 |

## 5. 敌人设计语言

威胁等级必须在剪影阶段成立，不依赖体型大小以外的信息。另设一条贯穿全篇的可读线索：**钟面状态**。

| 等级 | 钟面状态 | 含义 |
|------|----------|------|
| 小怪 | 钟面破碎或空白，无指针 | 不操作时间，只消耗 |
| 精英 | 钟面完整，指针正走 | 会按固定节奏行动 |
| Boss | 钟面完整，指针逆走并自发品红光 | 会改写时间轨 |

### 剪影差异原则

| 等级 | 剪影规定 |
|------|----------|
| 小怪 | 剪影可被单一凸包近似容纳；外突肢体不超过 4 处；无冠状轮廓；高度不超过画幅 60%；侧向或 3/4 姿态，禁止正面对称 |
| 精英 | 剪影必须有且只有 1 处"冠"，即头饰、背负武器或身体破口构成的单一识别特征；外突 5–8 处；高度 65%–80%；3/4 侧身 |
| Boss | 剪影横向跨度不低于画幅 85%；正面对称；具备两层轮廓，即主体加环绕漂浮构件；头部落在画面上 1/3 |

正面完全对称是 Boss 的专属特权。非 Boss 素材出现正面对称即打回，因为它会让玩家误判威胁等级。

## 6. 品红回响的使用纪律

品红（#e0399a）默认禁止出现。仅以下四种情形允许，且单张素材内品红像素占比不得超过 5%。

| 允许情形 | 说明 |
|----------|------|
| 回响本体 | 时间轨上正在重演的残影、分身、延迟轮廓 |
| 直接操作回响 | 该牌或该敌人的效果就是复制、延长、提前或抹除回响 |
| Boss 逆走钟面 | 仅限钟面本身及其直接照亮的一圈表面 |
| 第三幕环境光 | 仅限第三幕，且以环境光形式出现，不涂在主体上 |

明确禁止：作为背景等离子云、作为氛围雾、作为通用魔法光效、作为紫罗兰或紫色的替代品、作为填充空白区域的装饰。

补充约束：`strip` 预设使用纯品红 #FF00FF 作为抠像底色，与本色板的品红相邻。因此**所有走 strip 的素材一律不得包含品红元素**，回响光效由 `src/fx/` 在运行时叠加。

## 7. 质量红线

以下任意一条成立即必须重做，不接受局部修补。

1. 画面出现文字、字母、数字、可读符文、签名、水印。
2. 出现卡框、边框、UI 构件、血条、按钮。
3. 主体贴边或被画幅裁切；主体的发光外扩越过安全边。
4. 声明为透明底的素材实际不含 alpha 通道，或画面里被画出仿透明的棋盘格。
5. 透明底素材的背景存在渐变、投影或环境色溢出，导致抠像后留下彩边。
6. 品红占比超过 5%，或出现在第 6 节四种情形之外。
7. 主体自带无法解释来源的光，或使用正面平光。
8. 64 px 缩略下无法辨认所属类别或威胁等级。
9. 主色漂移为紫罗兰、洋红或蓝紫，而非规定的深靛蓝与午夜蓝。
10. 非 Boss 敌人素材呈正面完全对称。
11. 卡牌素材的构图轴与其所属类别（织／引／扰）不符。
12. 背景结构与主体同等锐度，主体与背景分离失败。

## 8. 生产约束

### 透明底不可依赖

实测生成后端忽略透明背景请求：`enemy` 类返回的 PNG 为 colortype 2（RGB，无 alpha），且画面中被绘制出模仿透明的浅色棋盘格。因此 `enemy`、`relic`、`ui` 三类不得依赖后端的透明底，必须走纯色抠像底加 `tools/sprite/` 的抠像步骤。

### 尺寸不可依赖

请求尺寸与返回尺寸不一致。所有版式规定使用比例，UI 侧按比例定位，不硬编码像素。

### 细节密度

`STYLE_CORE` 中的高细节倾向会在缩略尺寸下形成噪点。审片一律在实际显示尺寸下进行，不在原图尺寸下进行。

## 9. 应做与禁止

| 应做 | 禁止 |
|------|------|
| 先看剪影再看细节 | 用颜色区分卡牌类别 |
| 在实际显示尺寸下验收 | 在 100% 原图下验收 |
| 主光统一左上，补光统一右下 | 每张素材自定义光源方向 |
| 品红对应一条明确规则 | 品红作为氛围色铺满背景 |
| 背景虚化，主体锐利 | 背景与主体同等锐度 |
| Boss 专用正面对称 | 小怪使用正面对称 |
| 走 strip 的素材剔除全部品红 | 在抠像底色附近使用相邻色相 |
